What a seat run is evidence of, and what it is not

A passing run satisfies a rubric written in this bundle, measured on a schematic simulator written in this bundle, against a scripted reference operator also written in this bundle. It certifies nobody. 0 of 111 halls carry a practitioner sign-off, so no hall in this pack has had its content signed by the people who do the work.

  • what a run is scored againstdeterministic: every rubric axis is computed from measured state; nothing narrative can change a score
  • what the seat isschematic physics for practising control discipline - smooth inputs, swing management, ordered procedure. Not equipment certification; no seat time here counts toward one, and the assessment gates still demand unaided verification runs.
  • what the reference operator isSCRIPTED: a demonstration of a hand-written, deterministic control policy on a schematic single-machine simulator - a function of the seat's own gauges, the scenario's params and a level, no model behind it and no network reached. Not a learned policy, not real equipment, and not a claim about any physical robot; its runs are its own record, never credited to the learner watching it.
  • who wrote the rubricunverified general practice, written to be reviewed, corrected and replaced by journey-level practitioners from the halls each seat names. Nothing here cites a jurisdiction, a standard or an authority, nothing here speaks for one, and no rubric line, walkaround point or fault action is an instruction from one - a hall that adopts a seat owns what it says.
  • what the lesson content islesson content is unverified general practice pending authoring by journey-level practitioners
  • whose taxonomy this isa taxonomy of skilled trades, not a roster of chartered locals; no union has reviewed or endorsed it

What the control plane actually does with a rung

The rule that shapes everything here: BKT alone never certifies. A posterior is a belief; a gate needs demonstrated, unaided performance at or above the learner's own level. Propagated graph credit (ACP-15) explicitly does not count — a learner is certified on what they showed, not what was inferred.

Governing rule — INDIRECT EVIDENCE IS NEVER DIRECT EVIDENCE. Propagated credit moves theta but barely moves sigma, and never counts toward a gate. A learner is certified on what they demonstrated, not on what was inferred about them.

Certification requires all three tiers — no shortcuts. control/gates.mjs writes it as:

return skillGates.every((g) => g.pass) && levelTest?.pass === true && jobsiteFinal?.pass === true;
const pass = stepOrder >= 0.9 && safetyViolations === 0 && timeWithinTolerance && oral >= 2;

Nothing on this page meets that. A seat run is not a skill gate — a gate needs demonstrations stamped as qualifying at serve time by the sequencer — it is not the level test, and it is not the jobsite final, whose oral component is a person from the hall asking the learner to explain the why.

How the reference operator is run

Every rubric axis is measured, never judged: deterministic: every rubric axis is computed from measured state; nothing narrative can change a score. The bundle drives each seat with a scripted operator at 3 levels, so a pass bar is a bar something has actually cleared:

optimalthe reference: the written procedure with its checks and waits intact - passes every pass-gated rubric axis on every regional scenario, proven by the build
novicethe same procedure with seeded, deterministic slips - a mis-selected rack, a wrong signal, a wandering standoff, a low carry - so the sweep also yields labelled sub-optimal episodes
hurriedthe same procedure with its waits and checks removed - no settle before release, no containment before the trigger, no chart read before the hook - the failure a rushed shift actually produces

Across the 11 seats there are 46 rubric axes, of which 34 carry a pass bar and 12 are recorded but not scored.
