SmartCiti.X : Trade Craft Academy — verify a record

SmartCiti.X : Trade Craft Academy (powered by AGI Corp) · pack 3.2.0 · check an exported tc-completion/1, tc-contribution/1 file with the verifiers' own code, in this tab

A learner's completion record or contribution package is a file. This page checks it with exactly the rules node completion/verify.mjs and node contrib/verify.mjs run — the same code, carried into this page when it was built — and shows every rule's result.

  • NOTHING IS UPLOADED. The file is read in this tab and sent nowhere: this page makes no network request of any kind.
  • A KEY, NOT A PERSON. A signed file names the wallet address recovered from its signature. That is the identity of a key, not of a person; a key is held, lent and stolen. Nothing is on any chain.
  • A PASS IS NOT AN ACCREDITATION. A pass means the file is intact since export and every id in it exists in this bundle. Read the last line of every result.
