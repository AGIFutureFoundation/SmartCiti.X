What this is, and what it is not

  • Every software member is a SCRIPTED role and every robot is an AUTHORED simulated robot. No AI model runs behind any of them.
  • Simulation only. Nothing on this page, and nothing in the swarm code, sends a command to a real robot or a device.
  • A path to real hardware is refused by default. Real hardware needs a named human operator, and none is configured.
  • A dry run is a schematic simulation of an authored task. Its numbers say nothing about how a physical robot would behave (the sim-to-real gap).
  • A robot’s position on the map is a place in a simulation, set by a documented rule. It is not a statement that a robot exists there.
  • No learner location is stored or sent. This page never asks where you are.
  • Geohash is used as a plain grid for addressing. No conformance to any robotics or fleet-management standard is claimed.
  • This page stores nothing and sends nothing. The Style menu keeps your chosen style on this device, as on every page.

The registry’s own words, in English:

  • real hardware needs a named human operator; none is configured swarm/registry/swarm.json real_hardware.refusal
  • Every software member is a SCRIPTED role already in the Omega Hive or Omega Claw registries; every robot is an AUTHORED simulated robot. No AI model runs behind any of them (models: 0).
  • Nothing in this pack sends a command to a real robot or a device. Every routed command is a dry run against the robotics arena worlds, and every robot command passes through safety_gate/ first.
  • real hardware needs a named human operator; none is configured. No code in swarm/ sends anything to a robot or a device. The router has no real-hardware path at all, so naming an operator does not open one: a command that names real hardware, a live mode, an operator or a target outside this registry is refused with the sentence above.
  • The safety gate decides whether a person may enter a hazardous training station or simulator seat. It is not a real-world safety system. It is not a real-world safety system and no standard is claimed. A simulated robot holds no induction, PPE or permit, so a hazardous seat holds its command; a world the gate has no record for runs as a headless dry run and the audit row says so.
  • No learner location is stored or sent. Robot and role positions are poses already in the repo (campuses, anchors, restoration sites) or the centre of a parish outline, never a person.
  • Positions are copied from spatial/registry/geopose.json (horizontal only; height and heading are UNKNOWN there and unused here). A pose is a map anchor, not a parcel.
  • A dry run is a SCHEMATIC simulation of an AUTHORED task. Its numbers say nothing about how a physical robot would behave.
  • Geohash is used as a public-domain cell scheme; this pack makes no conformance claim to any robotics or fleet-management standard.

How the router decides

  1. Simulation only. Every command the router accepts becomes a dry run: one scripted episode of a simulated task.
  2. Real hardware is always refused. A command that names a device, a live mode, an operator or a target outside the registry gets this answer, and naming an operator does not change it: real hardware needs a named human operator; none is configured
  3. A target the safety gate holds no record for runs only as a dry run. In any other mode it is held, with this reason: no safety record for this target: held
  4. Every robot target is checked against the safety gate before its dry run, and is held if the gate says no. The gate holds a robot whose task is a hazardous simulator seat.
  5. No AI model is involved. The router, the hives and the dry runs are scripted and give the same answer for the same command.
  6. Every command writes one audit row, refused commands included. The log lives in memory; this page writes none.
  7. This is not a real-world safety system. The gate belongs to a training simulator, and no standard is claimed.

Limits
  • Geofence edges are straight lines in latitude and longitude, not great circles.

  • Robot positions come from a documented rule, not from a survey.
