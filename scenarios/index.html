SmartCiti.X — Training Scenarios

Six runnable simulation scenarios for the learner platform. Pick one, work its five steps in order, and check each step off as you complete it. Progress lives only on this page — nothing is stored or sent.

Demo mode — Sample data, not real learners. Simulation only — NOT certification, licensure, or clinical training.
SmartCiti.X is proposed, not incorporated / funded / offered. Louisiana + Indiana training sites are proposed/planned — no site, city, or address has been named. The 111-hall roster in the SmartCiti.X bundle is an in-repo list; 0 of 111 signed off by a named practitioner — a named hall is not a partner.
