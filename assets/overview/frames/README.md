# Captured frames

Stills taken from the **running application** by ,
which drives the real page and screenshots it. None of these is a mock-up, a
render made for the camera, or a still that was touched up afterwards. If a
surface is broken the frame shows it broken - that is the only way a
promotional image is worth anything to the people building the thing.

Captured 2026-09-22 at 1920x1080.
Re-take them by running a local server and then the capture script; the
script exits non-zero if the page throws while it is shooting.
