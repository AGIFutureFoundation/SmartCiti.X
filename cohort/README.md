# Cohort Dashboard v1 (Sprint S4)

SmartCiti.X : Trade Craft Academy, powered by AGI Corp: the cohort dashboard and skill map, built from a **synthetic** session log.

> **Synthetic data, not real learners.** Every row in `fixtures/session_log.jsonl` was generated by `synth_log.py` with a fixed seed. The 24 learners (`L01`..`L24`) are fictional pseudonyms with no identity behind them.

## Files

| File | What it is |
|---|---|
| `synth_log.py` | Python stdlib generator. Writes `fixtures/session_log.jsonl` deterministically (seed `20261012`). `--stdout` prints the same bytes and writes nothing. |
| `fixtures/session_log.jsonl` | Line 1 is the header `{"synthetic":true,"note":"generated test data; no real learner",...}` (it also carries the pack_version from `pack/manifest.json`). Every other line is either a `telemetry` or an `audit` row. |
| `dashboard.mjs` | Pure functions (`parseLog`, `computeDashboard`): raw log + registries in, figures out. No I/O, no clock. |
| `build.mjs` | Writes `dashboard.html`, one static, self-contained page: inline CSS, no script, no external fetch. `--stdout` prints the same bytes and writes nothing. |
| `dashboard.html` | The rendered dashboard. It carries the banner "Synthetic data — not real learners". |
| `test.mjs` | The S4 gate plus the privacy, determinism and registry checks. |

```
python3 cohort/synth_log.py && node cohort/build.mjs && node cohort/test.mjs
```

## Log shapes (from the repo, not invented)

- **telemetry**: the ACP-01 envelope that `bus/telemetry.mjs` `envelope()` builds. Its fields are `event_id, ts, clock_skew_ms, ts_source, learner_id, session_id, context{module_id, skill_ids, difficulty, modality, device_tier, scaffold_level}, verb, payload`. The verbs used are `attempted`, `hint_requested` (`payload.rung` 1..5), `completed` and `failed` (`payload.latency_ms`). The payload also carries `course`, `module`, `stage` and `attempt_id`. `module_id` is `<course>.m<n>.<stage>`.
- **audit**: `safety_gate.allow` / `safety_gate.deny` rows in the `bus/audit.mjs` AuditLog shape. `skill` is the simulator target, which is one of the course's `floor_sims` from `sims/registry/sims.json`. They are written before each floor-stage run on a course that has a simulator seat.
- Courses, modules and the stage order (`home → class → floor → gate`) come from `courses/registry/courses.json`. Skill ids are `<hall>.<strand>.<tier>` from `pack/registry/skills.json`.
- **The module→strand mapping is synthetic.** The courses registry gives each course its halls but does not give a module a strand. The generator therefore declares `module n → safety, tools, procedure, inspection, troubleshooting` and takes the tier from the course level (Foundation→fundamentals, Apprentice→applied, Journey→mastery). The log header records this mapping. The three courses with no hall (TCA-210/220/230) carry `skill_ids: []`, and the dashboard shows "no skill-graph mapping" for them.
- The gate (verify) stage is hint-free, matching the task ceiling in `control/hints.mjs`.

## Figures

- **Per learner:** stages completed / available across enrolled courses, gate pass rate, minutes on task (sum of `latency_ms`), hint count and mean rung, and safety-gate refusals.
- **Per course (cohort cells):** stage completion overall and by stage, gate pass rate (passed gate attempts / gate attempts), minutes per learner, hints per non-gate attempt, mean hint rung, and safety-gate refusals and refusal rate on the course's floor simulators.
- **Hint-rung usage:** requests per rung, with the count of learners behind each rung.
- **Skill map:** for each skill id, the mastery estimate is the mean over learners of each learner's mean attempt score. A pass scores the `creditFor()` value of its deepest hint rung (unaided 1.00, down to co-complete 0.25) and a fail scores 0. This is a descriptive cohort figure. It is not the ACP-15 posterior, and it certifies nothing.

## Privacy

- **Small-group protection:** `security/privacy.mjs` classes cohort figures as `CLASS.AGGREGATE` but defines no threshold. `dashboard.mjs` therefore declares `MIN_CELL_N = 5`. Any cohort cell that rests on fewer than 5 distinct learners is suppressed: it has no value and is shown as `n<5`. Per-learner rows are pseudonymous behavioural data and are shown as-is, because no cohort is aggregated in them.
- **Affect is never exported:** the generator never writes an affect field. `computeDashboard` also drops any row whose keys at any depth match `NEVER_EXPORT` or `NEVER_STORE`. The tests plant an affect-bearing row and check that it never reaches a figure or the page.

## The S4 gate

`test.mjs` recomputes every dashboard figure from the raw JSON lines by a separate route and requires agreement within 1%. That route groups hints with the next outcome in the same session rather than by `attempt_id`, and it uses its own copy of the hint-credit rule. A mutation check confirms the gate works: inflating one figure by 2% makes the gate fail.
